# Michael Agent Lab

我協助工程與技術專案團隊評估、試做 AI Agent 工作流程。從一項具體工作開始，釐清資料來源、人工確認點與驗收方式，再決定是否擴大導入。

可以討論的工作包括文件與版本差異整理、待辦追蹤、測試資料整理，以及 Agent 共用知識的審核流程。合作前會先確認範圍、交付內容與費用。
